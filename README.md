# StoryVerse AI

AI-powered interactive storytelling with solo play, multiplayer rooms, character handoff and branching timelines.

## Architecture
- `mobile/`: Expo React Native client
- `backend/`: FastAPI server
- `docs/`: product and architecture notes

## Status
Early prototype. No production authentication, persistent database, real-time multiplayer or LLM integration yet. Never commit API keys.

## Roadmap
1. Solo story creation and chat
2. Persistent world state and immutable timeline snapshots
3. Private branch rooms
4. Multiplayer and AI character handoff
5. Community story discovery and monetization
