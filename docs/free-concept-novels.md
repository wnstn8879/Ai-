# 장르를 고르지 않는 자유 주제 소설 창작

사용자가 정해진 장르나 줄거리를 고르는 대신, 섞고 싶은 소재·세계·인물·원하는 감정을 자유롭게 입력합니다. 김치 발효의 내공, 총을 쓰는 좀비, SF 우주 던전과 무협을 동시에 요구해도 기존 판타지로 정규화하지 않습니다. AI가 모든 조합을 설득력 있게 쓸 수 있다는 보장은 아니며, 세상에 한 번도 등장하지 않은 발상인지도 보장하지 않습니다.

## 이번 구현

온라인 앱의 로그인 후 첫 화면을 ‘소설 창작’으로 바꿨습니다. 자유 주제를 입력해 원문을 먼저 저장하고, 모델 호출은 별도 생성 버튼으로 실행합니다. 생성 실패에도 원문이 남습니다. 작품을 읽고, 원하는 창작 방향을 입력해 다음 장면을 쓰며, 특정 장면/저장 지점에서 원본을 보존한 다른 소설로 분기합니다. 작가의 지시와 실제 소설 본문을 독서 화면에서 구분합니다.

방에는 `narrative_format=novel`을 저장합니다. 소설 전용 프롬프트는 낯선 재료의 보존, 재료 사이의 인과/대가/한계, 인물의 욕망과 감정적 결과, 서술·대화를 요청합니다. 기존 역할극의 5회 AI 응답/짧은 문장/게임 선택 규칙을 소설에 적용하지 않습니다. 공급자 어댑터와 일일 한도·원자적 저장·요청 영수증·안전한 재시도 큐를 재사용합니다.

`006_novel_format` 마이그레이션은 rooms에 문자열 필드를 추가하고 기존 기록을 roleplay로 유지합니다. 원문과 기존 메시지를 다시 쓰거나 삭제하지 않습니다. 저장 지점에서의 재개와 분기도 소설 형식을 보존합니다. 소설은 소유자/참가자 권한으로 보호하며 공개 작품 게시 기능은 추가하지 않았습니다.

## 범위와 남은 일

새 화면은 AI 서버에 연결하는 온라인 앱에 있습니다. 이미 배포한 기기 선택형 체험 APK가 자유 생성 AI로 변한 것은 아닙니다. 최신 온라인 UI APK 설치, 실제 모델의 이 조합에 대한 소설 품질/속도, 상시 서비스 연결은 아직 검증하지 않았습니다. 자동 테스트에서 모델 응답은 HTTP/함수 대역이며 창의성에 대한 실사용 평가로 보지 않습니다.

후속 온라인 창작실에서 구절 단위 분기와 인물 관계·감정·기억의 수동 편집을 연결했습니다. [현재 온라인 체험](online-preview.md)을 참고하세요. 긴 소설의 자동 요약·기억 검색, 소설 편집·공개·다른 독자의 분기·소설의 게임 변환은 후속 기능입니다. AI 연결은 기존 최근 문맥과 상태를 사용하므로 무제한 장편 일관성을 보장하지 않습니다.

경쟁 서비스에 대한 사실도 구분합니다. AI Dungeon 공식 [Story 모드](https://help.aidungeon.com/faq/story-mode)는 자유 서술과 독립된 소설 쓰기를 지원합니다. 따라서 자유 입력 자체가 IMAGINE만의 독점 기능이라는 주장은 하지 않습니다. IMAGINE에서는 낯선 조합을 쉽게 시작하고 감정이입할 작품으로 읽고 재창작하는 경험을 차별화 가설로 검증합니다.

## 검증

백엔드 62개와 모바일 37개 테스트, Android JS/Hermes 번들 생성이 통과했습니다. 마지막 형식 검증/문맥 변경 후 소설·장면 지침 12개를 추가 확인했습니다. 테스트는 임의의 혼합 주제 보존, 소설 전용 프롬프트, 개인 접근 권한, 원문/장면 저장, 실패 무손상, 형식과 기록의 분기 보존, 기존 DB 유지와 기본 역할극 형식을 검사합니다. 실제 모델이 새 조합을 얼마나 재미있게 쓰는지와 최신 화면의 실제 기기 조작은 아직 검증하지 않았습니다.
