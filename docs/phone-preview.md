# 휴대폰에서 직접 여는 StoryVerse 체험판

이 체험판은 PC, USB, Expo Go, 회원가입, 인터넷 없이 실행하는 Android 앱입니다. 실제 화면에서 짧은 이야기·대화·기기 자동 저장·저장 지점·평행세계 분기를 확인하기 위한 버전입니다. 이야기 내용은 미리 작성된 선택형 시나리오이며 실제 LLM 응답이나 멀티플레이로 표시하지 않습니다.

## 설치

1. 전달된 `StoryVerse-Preview.apk`를 Android 휴대폰에 다운로드합니다.
2. 다운로드한 APK를 열고 설치합니다. Android가 설치 권한을 요청하면 APK를 여는 브라우저 또는 파일 앱에 해당 권한을 허용합니다.
3. 앱 목록에서 **StoryVerse 체험**을 엽니다. 기존 StoryVerse 개발 앱과 별도 패키지이므로 함께 설치할 수 있습니다.
4. **새 이야기 시작**을 누릅니다. 별도 서버 주소나 API 키를 입력할 필요가 없습니다.

Android 7.0 이상 arm64 기기와 x86_64 에뮬레이터를 대상으로 빌드합니다. 32비트 전용 기기는 이 APK에 포함하지 않습니다. 내부 테스트용 서명이며 Play Store 운영 배포본은 아닙니다.

## 직접 확인할 흐름

- 홈: 글자 크기와 카드·버튼이 편한지 확인합니다.
- 새 이야기: 선택 버튼으로 진행하거나 직접 행동을 입력합니다. 자유 입력은 기록되며 준비된 시나리오 순서로 진행합니다. 실제 AI의 문맥 이해를 테스트하는 버전은 아닙니다.
- 자동 저장: 행동을 보낸 뒤 앱을 완전히 닫고 다시 엽니다. 보관함의 ‘이어서 플레이’에서 대화가 남아 있는지 확인합니다.
- 초안: 행동을 적고 ‘초안 저장됨’을 확인한 뒤 앱을 종료합니다. 다시 들어가 입력이 복원되는지 확인합니다.
- 저장하고 쉬기: 보관함으로 돌아간 후 같은 이야기를 이어봅니다.
- 저장 지점: ‘저장 지점 · 타임라인’ → ‘현재 장면 저장’ → 이후 대화 진행 → 해당 저장 지점에서 새 분기를 만듭니다.
- 과거 선택: 타임라인에서 원하는 메시지의 분기 버튼을 누릅니다. 원본과 새 분기가 보관함에 각각 남고, 새 분기의 행동이 원본을 바꾸지 않는지 확인합니다.
- 짧은 끝맺음: 약 네 번의 선택으로 준비된 장면의 결말에 도달합니다. 끝나면 쉬거나 다음 장면으로 계속할 수 있습니다. 여러 장편 시나리오가 포함된 버전은 아닙니다.
- 작은 화면과 키보드: 입력 시 버튼이 가려지지 않는지, 긴 문장이 잘리는지 확인합니다.

화면 문제를 알려줄 때는 기기 모델, Android 버전, 누른 버튼, 기대한 동작과 실제 동작을 함께 알려주세요.

## 저장 범위

기록은 `storyverse-preview-v1.db`라는 앱 전용 SQLite에 저장됩니다. 대화와 상태를 같은 트랜잭션으로 보존하며, 전송한 입력과 일치하는 초안만 함께 비웁니다. 저장 실패 시 원본과 초안을 유지합니다. 저장 지점은 당시 상태를 고정하고, 분기는 선택 위치까지 복사해 원본을 보존합니다. **앱 삭제 또는 앱 데이터 삭제 시 이 체험 기록도 사라지며 계정/다른 기기와 동기화하지 않습니다.**

체험판은 `com.storyverse.ai.preview`, 온라인 개발 앱은 `com.storyverse.ai`를 사용합니다. 온라인 계정·서버 기록은 이 버전에 복사하지 않습니다. 기존 온라인 인증·친구·멀티플레이·AI 어댑터는 저장소에 유지합니다.

## 빌드와 검증

전용 GitHub Actions 워크플로 `.github/workflows/android-preview.yml`이 Expo prebuild 후 `assembleRelease`로 JS/Hermes 번들을 포함한 APK를 만듭니다. 다운로드 아티팩트에는 APK와 SHA-256 체크섬이 포함됩니다. Metro가 필요한 기존 debug APK와 구별해야 합니다.

`mobile/scripts/preview_smoke.py`는 서버/Metro를 시작하지 않고 비행기 모드, Wi-Fi/데이터 끄기, ADB reverse 제거 후 앱 설치·실행·선택·초안 재시작·체크포인트·분기·보관함 재시작을 확인합니다. 화면과 결과 JSON, logcat을 별도 증거 아티팩트로 남깁니다. 실제 휴대폰 검증과 에뮬레이터 검증을 구분해서 보고합니다.

로컬 Node 테스트 33개가 통과했습니다. 이번에 추가한 8개는 실제 SQLite 파일 재열기, 모든 메시지에서 분기, 상태 복원, 체크포인트 고정, 실패 롤백, 초안 보존, 동시 요청과 두 결말을 검증합니다. Android 번들도 생성했습니다. APK 빌드와 네이티브 검증의 최종 결과는 후속 기록에 명시합니다.
