# IMAGINE 비공개 테스트 준비

출시 순서는 짧은 싱글플레이 → 저장/분기 신뢰 → 실제 AI 속도/품질 → 친구 탐험으로 유지합니다. 이번 단계는 첫 두 경험을 휴대폰 단독 체험판에서 검증합니다. 다섯 보완점 전체가 끝났거나 출시 준비가 완료됐다는 뜻은 아닙니다.

## 실제 반영한 변화

- 처음에는 세계관 양식을 작성하지 않고 ‘새 이야기 시작’ 한 번으로 미스터리에 들어갑니다.
- 신규 사건은 최대 네 번의 명시적 선택, 네 가지 결말을 갖습니다. 주인 확인 단서와 봉투/편지 처리 선택이 결과를 바꿉니다. 전체 12경로를 자동 검사합니다. 초 단위 플레이 시간은 보장하지 않습니다.
- 알 수 없는 자유 입력은 기록하되 선택이나 행동 결과를 임의로 확정하지 않습니다. 체험판은 작성된 선택형 콘텐츠임을 표시합니다.
- 보관함에 마지막 장면 요약과 저장 확인 시각을 표시하고, 개인 분기에서 원본 이야기로 돌아갈 수 있습니다.
- 사건 완료 후 자동으로 같은 내용을 반복시키지 않고, 다른 선택은 원본을 남기는 새 분기로 시작합니다.
- 기존 version 1 기록은 원래 시나리오대로 유지합니다. 신규 기록은 storyVersion=2와 단서 상태를 각 메시지의 stateAfter에 보존합니다. DB 스키마 변경 없이 기존 SQLite 파일을 사용합니다.

## 테스트 모집 전 확인

1. 설치: 전달 파일이 실제 Android에서 다운로드/설치/실행되는지 확인합니다. 파일 링크가 안 열리는 것과 APK 설치 실패는 별도 문제로 기록합니다.
2. 첫 사건: 설치 후 설명 없이 시작하게 하고, 선택을 이해하는지 관찰합니다.
3. 종료/복원: 한 선택 후 앱 강제 종료 → 재실행 → 요약 확인 → 이어서 플레이.
4. 저장/분기: 마지막 장면 저장 → 다른 선택 진행 → 저장 지점 또는 과거 메시지에서 분기 → 원본/단서 상태 비교.
5. 키보드/화면: 작은 화면, 큰 글꼴, 입력 중 스크롤을 점검합니다.

## 20~30명 비공개 테스트 기록

이는 모집/측정 계획이며 사용자 조사 결과가 아닙니다. 수치는 실제 테스트 후 채워야 합니다. 외부 분석 SDK를 추가하거나 이용자 대화를 자동 수집하지 않았습니다.

| 항목 | 정의 | 기록 방식 |
| --- | --- | --- |
| 설치 성공 | APK 수신자 중 실제 첫 화면을 연 사람 | 기종/Android 버전/성공 여부 |
| 첫 사건 완료 | 사건을 시작한 사람 중 하나의 결말까지 간 사람 | 시작·완료 시각과 중단 위치 |
| 다음 날 이어하기 | 첫 플레이한 사람 중 다음 날 자발적으로 복귀한 사람 | 모집일별 집단과 복귀 기록 |
| 분기 사용 | 플레이한 사람 중 새 분기를 만들고 추가 선택한 사람 | 분기 지점·이어한 선택 여부 |
| 저장 신뢰 | 종료/재실행/분기 후 기록이나 단서가 누락된 경우 | 재현 절차·원본/분기 비교 |
| AI 비용/속도 | 실제 AI 서버에서 성공한 턴과 실패한 시도의 지연/리소스 사용 | 공급자별 측정, 무료 작성형 체험과 구분 |

설문은 ‘재미있었나요?’만 묻지 않습니다. 다시 선택해보고 싶었던 장면, 결과가 납득되지 않은 선택, 기다리다 그만둔 위치를 물어봅니다. 현재 체험판의 재방문율을 실제 AI 서비스의 유지율로 해석하지 않습니다.

## 남은 순서

- 휴대폰 실기기 검증/설치 경로와 비공개 모집: 실제 사용자의 기기에서 확인이 필요합니다.
- AI: Qwen 어댑터와 실호출 저장/분기는 완료됐지만 CPU 24초 응답 및 문장 품질 문제는 해결되지 않았습니다. GPU/모델 비교, 첫 응답 표시와 실패 복구를 검증해야 합니다.
- 상시 서비스: HTTPS API·DB 백업·계정 복구·서명·서버 비용을 확정해야 실제 AI 앱으로 배포할 수 있습니다. 기기 체험판의 기록은 계정/클라우드와 동기화되지 않고 삭제 시 복구되지 않습니다.
- 친구 탐험: 기존 초대/권한/WebSocket/공용 저장 코드를 유지하되 싱글플레이 테스트 이후 실제 두 기기로 검증합니다.

## 이번 단계 검증 결과

모바일 테스트 37개, Android 번들 및 APK 빌드가 통과했습니다. [단독 Android 검증 #7](https://github.com/wnstn8879/Ai-/actions/runs/44251704892)에서 비행기 모드로 설치·선택·초안 재실행·체크포인트·과거 메시지 분기·네 선택 완주·저장하고 쉬기·보관함 재실행이 통과했습니다. 실제 캡처 화면을 확인했습니다. 검증 코드 커밋은 `e345a28`이며 앱 기능 커밋은 `377cb94`입니다.

초기 두 실행은 고정 헤더에서 스크롤을 시작하거나 빠른 스와이프가 목표를 지나치는 자동 검사 문제로 실패했습니다. 실제 ScrollView 영역과 잘린 목표 위치를 사용한 느린 스크롤로 수정한 뒤 전체 검사가 통과했습니다. 이 실패들을 앱 검증 성공으로 합산하지 않습니다.

[검증 APK 다운로드](https://github.com/wnstn8879/Ai-/actions/runs/44251704892/artifacts/14404557057)는 ZIP 안의 `StoryVerse-Preview.apk`를 설치하면 됩니다. 표시 이름은 IMAGINE 체험입니다. 기존과 같은 패키지/테스트 서명을 사용하며 SQLite 구버전 재열기 호환성을 검사했습니다. 실제 기기 업데이트와 터치 검증은 아직 미수행입니다.
