# IMAGINE

Your Story, Your World, Your Choice.

AI 기반 참여형 스토리 창작·게임 플랫폼.

## 제품의 중심

사용자가 자신의 상상을 플레이할 수 있는 세계로 만들고, 혼자 또는 친구들과 함께 탐험합니다. 소설은 세계와 사건을 만드는 창작 경험이고, 게임은 그 세계에서 캐릭터를 맡아 선택하는 경험입니다. 두 경험을 연결하되 ‘AI 소설을 읽는 것’과 ‘같이 게임을 플레이하는 것’을 같은 기능으로 취급하지 않습니다.

앱에서는 배경/첫 사건, 세계관 규칙, 캐릭터, 탐험 목표를 정하고 플레이를 시작합니다. AI는 사용자의 행동을 대신 확정하지 않습니다. 함께 탐험할 때는 참가자마다 역할을 갖고, 혼자 계속하고 싶으면 현재 또는 과거 장면에서 개인 분기를 만듭니다.

짧은 출근길에는 작은 사건을 마무리하고 저장합니다. 원하면 시간 제한 없이 계속 플레이합니다. 모든 기록은 원본을 보존하고, 과거 장면 또는 저장 지점에서 독립된 평행세계로 재개합니다. 공용 방 복원에는 기존 방장/참가자 동의 규칙을 적용합니다.

## 구현 상태와 개발 순서

| 경험 | 현재 상태 | 다음 단계 |
| --- | --- | --- |
| 상상을 세계 설정으로 입력 | 온라인 모바일에 제목·배경/첫 사건·목표·규칙·캐릭터 입력. 기존 room/state에 저장 | 생성 전 설정 초안 보관, 플레이 가능한 사건/목표 구조화 |
| 혼자/친구와 플레이 | 인증·참가 권한·초대·WebSocket·캐릭터 배정 구현 | 사용자 휴대폰에서 상시 서비스로 연결, 협동 목표와 턴 규칙 검증 |
| 저장·재개·분기 | 서버 저장/스냅샷/개인·공용 분기 구현. 기기 체험판은 SQLite로 보존 | 분기 트리와 긴 기록 탐색 UX |
| 짧은 장면/장기 플레이 | AI 장면 진행 지침, 마무리 요청, 저장하고 쉬기 구현 | 실제 모델/이용자 플레이로 분량·긴장감 조정 |
| 소설 생성·읽기 | 별도 소설 모드 미구현 | 주제→세계 초안→소설 생성·독서→선택한 장면을 게임 출발점으로 변환 |
| 작품 공유·인기 IP | 미구현 | 공개 범위·원작/분기 표시·창작자 허용 범위 설계 후 공유 |

게임 전환은 소설의 문장을 채팅창에 붙이는 기능이 아닙니다. 장소·캐릭터·참가자 역할·현재 사건·목표·시작 상태를 정리한 뒤 사용자가 확인하고 플레이할 수 있어야 합니다. 소설 원문과 플레이 기록은 독립적으로 보존하는 방향입니다.

## 이번 코드 변경

- 앱 표시 이름과 홈/시작 화면 브랜드를 IMAGINE으로 변경하고 슬로건을 반영했습니다.
- 온라인 세계 생성 화면에 ‘상상하는 세계와 첫 사건’, ‘탐험 목표’를 추가했습니다. 단순 안내 문구가 아니라 기존 `world_rules`에 구획을 붙여 저장하며, 기존 상태 스냅샷과 AI 문맥·분기 복원을 그대로 사용합니다.
- 기존 Android 패키지·SQLite 파일·세션 키·저장소 이름은 유지합니다. 이름 변경만으로 기존 기록이 다른 앱으로 분리되지 않도록 했습니다. 서버 스키마/마이그레이션 변경은 없습니다.
- 휴대폰 단독 체험판도 IMAGINE으로 표시하되 미리 작성된 선택형 이야기임을 유지합니다. 체험판에서 자유 세계 생성·실제 AI·온라인 협동이 가능하다고 표시하지 않습니다.

## 제공 자료와의 관계

사용자가 붙여넣은 사업/발표 방향을 요구사항으로 정리했습니다. 실제 20쪽/16쪽 PDF와 HTML은 첨부되지 않아 읽거나 수정하지 않았습니다. 「천하제일검: 두 세계의 문」과 「붉은 달: 조선의 마지막 밤」의 실제 시나리오 데이터도 아직 전달되지 않았으므로 앱에 이식했다고 표시하지 않습니다. 다른 게임의 이미지를 IMAGINE의 실제 시연 증거로 사용하지 않고 실제 앱 캡처와 구분합니다.

## 배포 범위

기존 다운로드 APK는 StoryVerse 이름의 이전 체험판입니다. 이번 브랜드/온라인 생성 화면 변경을 포함하는 새 APK는 별도 빌드 검증이 필요합니다. 제품 목표는 휴대폰 단독 사용이며 실제 AI/온라인 협동을 일반 사용자에게 제공하려면 상시 HTTPS 서버·모델 키·서명 빌드·실기기 검증이 필요합니다. 기기 체험판에는 이 연결이 포함되지 않습니다.

검증: 변경 후 모바일 Node 테스트 33개와 Android JS/Hermes 번들 생성이 통과했습니다. 최신 UI 실기기 검증과 새 브랜드 APK 설치 결과는 아직 확인하지 않았습니다.
